# «Після титрів» — квитки, scanner і live display

## Запуск

1. Виконайте `npm run build`.
2. Запустіть `python3 -m http.server 8000 --directory dist`.
3. Запрошення: `http://localhost:8000/`; сканер: `/scanner/`; екран біля входу: `/display/`.

## Відкриті квитки та VIP-список

Звичайний квиток може створити будь-хто, ввівши ім’я. Сайт генерує унікальний `ticketId` і номер автоматично.

VIP-список редагується в одному місці — масив `vipGuests` у `dist/data.js`. Для VIP-запису задайте ім’я, унікальні `ticketId` і `number`, тип `teacher` та роль `HONORED GUEST`. Імена зі списку автоматично отримають особливий квиток.

## Supabase realtime

1. Створіть Supabase project і виконайте весь файл `supabase.sql` у SQL Editor.
2. Скопіюйте `.env.example` у `.env` і заповніть `VITE_SUPABASE_URL` та публічний `VITE_SUPABASE_ANON_KEY`.
3. Запустіть `set -a; source .env; set +a; npm run build`.
4. Опублікуйте `dist`. Service-role key у сайт додавати не можна.

Без env сайт працює в demo mode. Дані звичайного гостя безпечно передаються всередині його QR-посилання, повторний check-in зберігається у браузері scanner, а display синхронізується між вкладками цього браузера.

## Тест телефоном і ноутбуком

З Supabase: відкрийте `/display/` на ноутбуці, створіть квиток на головній, а `/scanner/` відкрийте на телефоні. Відскануйте QR з екрана. Перший скан зелений, повторний жовтий; викладацький квиток має окрему анімацію.

Без Supabase: відкрийте `/scanner/` і `/display/` у двох вкладках одного браузера та натисніть демо-квиток у сканері. Для чистого повтору видаліть ключі `premiere-used:*` у Local Storage.

`/scanner/` навмисно не показано в головній навігації.

## Збереження квитка на телефоні

На iPhone та Android кнопка «Зберегти квиток» відкриває системне меню поширення, де можна вибрати «Зберегти зображення». Якщо браузер не підтримує передавання PNG у це меню, квиток відкриється окремим зображенням — затисніть його та виберіть збереження у Фото.
